# Proyecto-quinto

Marketplace agrícola desarrollado por Derki, Yostin Ruiz y Santiago para la cooperativa de productores de Olmedo.

El sistema permite que un productor publique un lote con su precio por libra y sus existencias, y que un comprador busque café y consulte si está disponible.
